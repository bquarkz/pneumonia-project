# Sample X-rays

This folder is meant to hold 3–5 representative chest X-ray JPEGs so an evaluator can test the
full upload → processing → result flow without needing your full training dataset.

**It ships empty on purpose.** No real chest X-ray images are included here — this repository
was built without access to your image collection, and fabricating medical-looking image files
would be actively misleading rather than a harmless placeholder.

Before a demo or evaluation run, add a handful of JPEG files here yourself (any JPEGs work for
exercising the pipeline technically; use real, appropriately-sourced chest X-rays if you want
the demo to be medically meaningful — check you have the right to include/redistribute
whichever ones you pick, especially if this repository is later made public).
